# ADR-004：用“检测 → 确认 → SAM 2 → 逐帧修补 → 贴回原帧”作为视频删除的第一版管线

- 状态：已采纳（2026-10-28，调整后的 Week 3；数据见 `results/metrics.csv`）
- 相关人：Yarong Zhang（检测与跟踪）、Mingran Chen（修补与闪烁评测）、Zhihan Zhang（片段定位、替换与界面）
- 前置：ADR-002（SAM 2 + 框提示 + 外扩 6–8 px）、ADR-003（SDXL：替换好、删除易“编造”、生成结果必须贴回原图）
- 来源：10/22 Dr. Chen 与 Dr. Ranga 的会议建议

## 背景

10/22 两位教授的反馈：
- Chen：先试 OpenCV 里的模型；用 YOLO 检测出物体，让用户确认，再处理（半自动、“做自己的版本”）；关注删除后边缘的质量，以及视频里边界在帧间跳动的问题。
- Ranga：项目是视频——一段 50 秒的视频里杯子只出现 5 秒，怎么找到那一段？用检测标出目标再处理。

这一周第一次用组里拍的 5 段真实视频（`test_clips/`，720×1280，30 fps，10–26 秒）。任务按 `test_clips/requirements.txt`：每段删除纸杯咖啡；clip_C 再把纸袋替换成一本黑色的书。

## 决策

1. **检测**：YOLOX-S（OpenCV Model Zoo，Apache-2.0），用 **OpenCV dnn** 运行（新推理引擎只能用 CPU，约 0.05 秒/帧）。用途：
   - 找出目标出现的片段：clip_D 只有 5.2–8.5 秒有杯子，约 3/4 的帧（252/339）没有 mask、完全不处理
   - 挑关键帧：置信度最高、互相间隔 ≥1 秒的帧，检测框作为 SAM 2 的提示
2. **确认**：每段视频生成 `results/<clip>_confirm.png`（关键帧检测框 + 时间轴）。删除目标按 requirements.txt 确认；检测不到的目标（纸袋不在 COCO 类别里）由用户在关键帧上补一个框和几下点击——这就是“半自动”的那一步。
3. **跟踪**：SAM 2.1 large，多个关键帧框提示，正向 + 反向传播。**检测只决定“处理哪一段”，每帧有没有目标由 SAM 2 判断**：YOLO 在俯视等角度会漏检（clip_E 只有 75% 的帧检测到），但 SAM 2 在全部 778 帧都跟住了杯子，包括正上方俯视只看到杯盖的帧。
4. **逐帧删除**：mask 外扩 8 px 后，只裁 mask 周围的区域修补，再羽化贴回原帧。修补模型用 **LaMa**（专门做删除的模型，约 0.04–0.12 秒/帧），OpenCV Telea 作为对照。
5. **替换（clip_C）**：在一张关键帧上用 SDXL inpaint 生成黑色的书，再逐帧对齐合成。**书跟着纸袋本身的运动走**（纸袋区域内的 ORB 特征 → 相似变换），纸袋被手推动时书也跟着动；手在书前面时保留手；纸袋露出书外的部分用 LaMa 补掉。

## 依据

| 片段 | 方法 | 闪烁中位数 | 闪烁 p90 | mask 外 PSNR |
|---|---|---|---|---|
| A 固定机位 | 原视频（参照） | 1.53 | 1.90 | — |
| | Telea | 0.93 | 1.43 | inf |
| | **LaMa** | **2.38** | **3.91** | inf |
| B 手持 + 推近 | 原视频 / Telea / LaMa | 2.16 / 0.69 / 1.64 | 2.93 / 1.13 / 3.11 | inf |
| C 手拿杯子 | 原视频 / Telea / LaMa / LaMa+书 | 2.44 / 0.97 / 2.03 / 2.05 | 3.08 / 1.97 / 3.65 / 3.83 | inf |
| D 中段出现 | 原视频 / Telea / LaMa | 1.96 / 0.80 / 0.95 | 3.56 / 1.12 / 1.41 | inf |
| E 户外环绕 | 原视频 / Telea / LaMa | 1.58 / 0.69 / 1.03 | 2.73 / 1.10 / 1.43 | inf |

闪烁 = 编辑区域的帧间变化 ÷ 周围环带的帧间变化。数值本身要结合画面看：

- **Telea 闪烁最低，是因为它把区域抹成了没有纹理的色块**——色块本来就不怎么变。稳定，但内容是错的（竖向拖影、星形抹痕）。
- **LaMa 内容最合理**：隔板、桌面木纹、户外木条都能接上，clip_E 俯视时杯盖也删得很干净。
- **但 LaMa 在静止画面里会“闪”**：clip_A 背景几乎不动，LaMa 每帧独立重新生成纹理，闪烁 2.38，明显高于原视频的 1.53（见 `results/clip_A_flicker.png`）。镜头运动时（D、E）接近自然。这就是 Chen 提到的往届小组遇到的“边界在帧间跳动”。
- **保持度**：所有方法贴回原帧后 mask 外完全不变（PSNR = inf）。

## 发现的问题

1. **逐帧修补在静止画面里闪烁** → 下一周（Week 4）用专门的视频修补模型（VideoPainter，或者 ProPainter、DiffuEraser 等）和逐帧 LaMa 对比。
2. **阴影没有删掉**：mask 只包住杯子本身，桌上留下淡淡的杯影或倒影。需要把阴影纳入 mask（外扩更多，或者单独分割阴影）。
3. **手拿着的物体被删掉后，手像握着空气**（clip_C）：这是删除任务本身的语义问题，不是处理错误；替换任务更适合这种场景。
4. **替换用的是单张关键帧的“贴图”**：书会跟着纸袋移动和旋转，但不会随纸袋的挤压变形；手边缘有模糊。SDXL 第一轮会在黑书上多叠别的书或手机，提示词改成“单本、上面没有东西”后，6 个候选里有 5 个符合（seed 2 选用）。
5. **检测只认识 COCO 的 80 类**：纸袋这类物体需要用户补充提示。

## 后果

- 这版管线作为后面所有视频实验的入口：检测 → 确认 → SAM 2 的 mask 序列可以直接给视频修补模型和全局模型使用。
- 网页界面下一步把“确认”做成界面操作（显示 `_confirm.png` 的内容，让用户勾选目标或补点击），对应 Chen 说的半自动“自己的版本”。
