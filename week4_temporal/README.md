## 做了什么

| 负责 | 方法 | 原理 | 成本 |
|---|---|---|---|
| Mingran | **① 背景板** | 每帧和参考帧之间用 ORB 特征 + 单应矩阵对齐（只用 mask 外的背景）；物体不在的帧露出的真实背景取中位数，拼成“背景板”：整段一块全局板 + 每 1.5 秒一块局部板（只用前后 1.5 秒的帧，跟得上被推动的纸袋，相邻两块渐变过渡）；整段都没露出过的地方只在全局板上用 LaMa 补**一次**，局部板里离得太远才露出的地方在那块局部板上补；每帧把当时的背景板按镜头运动变形回来填进 mask，再按 mask 外一圈做亮度增益补偿，手保持在前面 | 每段 LaMa 1 次（逐帧方法要 300 多次）；对不齐时自动退回逐帧（见下方结果） |
| Mingran | ② 光流时间平滑（对照） | 第三周逐帧 LaMa 的结果，mask 内和“按 DIS 光流对齐的上一帧结果”加权平均（0.75 / 0.25） | 在逐帧 LaMa 之外再加约 70 ms/帧 |
| Zhihan | **③ 稳定 mask + 去光晕** | 杯子 mask 加上贴着杯子、偏暗的阴影 → 闭运算 → 外扩 12 px → 前后 2 帧取并集（边缘不再逐帧抖动）；镜头运动轨迹按中位数平滑，去掉单应估计的抖动 | 约 12 ms/帧 |
| Zhihan | **逐物体修补**（clip_C） | 杯子和纸袋分开处理：先用纸袋自己的 mask 和背景板去掉纸袋，再在去掉纸袋的画面上用杯子自己的 mask 和背景板去掉杯子，各自做增益补偿。和“两者合成一个大 mask 一起处理”对比 | LaMa 次数约翻倍 |
| Zhihan | 换书（clip_C） | 第三周 SDXL 生成的书，按纸袋自己的运动逐帧合成、手在前面；底图换成逐物体去掉杯子和纸袋后的结果，不再逐帧补“露出的纸袋” | 只有对齐，CPU |
| Yarong | **演示界面** | `demo_app.py` + `web\index.html`：选视频 → 检测确认图 → 勾选物体（删杯子 / 换纸袋 / 手在前）→ 选方法 → 原视频和结果同步播放 → 指标、放大图、背景板；可在后台重跑单段 | 不装新库 |
| Yarong | 文件处理 | 结果统一放在 `results\`（视频都是浏览器能直接播放的 H.264）；一键脚本；README / ADR / 实验记录 | — |

## 结果

见 `results\metrics.csv` 和 ADR-005。闪烁 = 编辑区域的帧间变化 ÷ 周围一圈的帧间变化（中位数；接近原视频 = 自然，明显更高 = 闪，明显更低 = 冻住）。
接缝 = mask 边界的梯度 ÷ 附近的梯度（≈1 = 看不出边）。

| 片段 | 原视频 | 第三周逐帧 LaMa | ② 光流平滑 | ① 背景板 | **Week 4 最终** | 最终模式 | 接缝：第三周 → 最终 | LaMa 次数：第三周 → 最终 |
|---|---|---|---|---|---|---|---|---|
| A 固定机位 | 1.40 | 2.11 | 0.57 | 0.40 | **0.30** | 背景板 | 0.94 → 0.93 | 316 → **1** |
| C 手拿杯子、推纸袋 | 2.28 | 2.05 | 0.99 | 1.00 | **1.14** | 逐帧（背景板对不齐） | 1.05 → **1.00** | 313 → 253 |
| D 镜头扫过 | 2.01 | 1.22 | 0.89 | 1.24 | **0.67** | 逐帧（背景板对不齐） | 1.17 → **1.02** | 87 → 91 |

- 换书（clip_C）：闪烁 2.09 → **1.59**；杯子原位置的拖影消失，手完整
- 逐物体 vs 一个大 mask（clip_C 杯子 + 纸袋）：闪烁 0.72 / 0.72，接缝 1.28 / **1.18**，耗时 99 s / **68 s** → 紧挨着的物体合成一个 mask 更好
- 最终方法会自动选择：背景板和当前帧在 mask 外一圈的平均差 ≤ 6 灰度级时用背景板，否则用 ③ 的新 mask 逐帧 LaMa + 光流平滑（光晕照样去掉）

## 已知问题

- 杯子在 clip_A 里从头到尾没动过，它后面的桌面从来没露出来，这块仍然靠 LaMa 补（只补一次，不闪，但补出来的木纹偏淡）
- 背景板假设背景近似平面（单应矩阵）；clip_D 这种镜头扫过、前后景有视差的画面，补丁边缘可能有轻微错位
- clip_C 杯子被手拿着时删掉后，手像握着空气（删除任务本身的问题）
- 书仍然是单帧贴图，不随纸袋变形
- ② 光流平滑的闪烁值比原视频还低：内容几乎冻住，而且第三周的暗条还在，所以只作对照
