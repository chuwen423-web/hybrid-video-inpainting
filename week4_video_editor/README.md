# 视频物体编辑器（完整流程，可处理新视频）

双击 **`start_editor.bat`** → 浏览器打开 http://127.0.0.1:8767 （只监听本机，黑色窗口不要关；Ctrl+C 或关窗口即可停止）。
和第一周图片界面（8765）、第四周结果演示界面（8766）是三个独立的网页，互不影响。

## 操作步骤

| 步骤 | 做什么 | 用时（RTX 5090 笔记本，720×1280、10 秒视频） |
|---|---|---|
| 1 选视频 | 上传视频，或选 `test_clips` 里的测试视频 → 自动抽帧 + YOLOX 逐帧检测 | 约 15 秒 |
| 2 选物体 | 检测到的物体（每类一个缩略图、出现的时间段）选 删除 / 替换 / 保持在前面；检测不到的物体（如纸袋）点 “+ Add an object”，在右边任选一帧拖框、加 + / − 点击（可以在多帧上标）；替换要选一张图片（上传，或用自带的黑书示例） | — |
| 3 跟踪 | SAM 2.1 large 跟踪全部物体，生成彩色 mask 预览视频；mask 不对就回第 2 步补点击再跟踪 | 约 1.5 分钟 |
| 4 编辑 | 删除：第四周的方法（稳定 mask + 阴影 + 背景板；背景板对不齐时自动改逐帧 LaMa + 光流平滑）；替换：原物体先删掉，图片按原物体自身的运动逐帧贴上去，手 / 人保持在前面 | 1–3 分钟 |
| 结果 | 原视频和结果同步播放，显示闪烁和接缝指标，可下载结果视频和左右对比视频 | — |

## 说明

- 视频最长处理 30 秒，长边超过 1280 会先缩小（显存和时间可控）
- 替换不调用 SDXL（不需要 ComfyUI）：用上传的图片（PNG 可以带透明背景），按原物体在关键帧（最完整、没被手挡住的一帧）上的外接框缩放、底边对齐
- 删除和替换的物体合成一个 mask 一起去掉（ADR-005：紧挨着的物体这样效果更好）；“保持在前面”的物体（例如手）不会被改动
- 每个任务的文件在 `jobs\<任务编号>\`（抽帧、检测结果、mask、结果视频，约 0.3–1 GB）；不需要时删掉整个文件夹即可，网址里的 `#任务编号` 可以重新打开任务
- 用第二周的 `.venv`（PyTorch + SAM 2 + OpenCV），模型复用 `week3_video_pipeline\models`（YOLOX、LaMa）和 `week2_mask_tracking\checkpoints`（SAM 2）

## 实测（clip_C，`jobs\cc84fd19\`）

删除杯子（检测）+ 纸袋换成黑书（手动 1 框 + 3 点）+ 手保持在前（检测 person）：
检测 16 s → 跟踪 91 s → 编辑 171 s；背景板对齐误差 11.7 → 自动用逐帧 LaMa + 光流平滑；编辑区域闪烁 2.09 → 1.49。
