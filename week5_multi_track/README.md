# 多目标识别与追踪（YOLOX + SAM 2）

双击 `start_tracker.bat`，浏览器打开 http://127.0.0.1:8768 （只监听本机，用第二周的 `.venv`，不装新库）。

页面顶部有两个标签：
- **Track a video**：处理新视频，流程见下文。
- **Test results**：只读展示 clip_C 和 clip_D 的最终测试结果，布局和处理新视频时的第 2、3 步一样。
  - 结果文件在 `jobs/4d06cc02` 和 `jobs/ef36290b`，在 `track_app.py` 的 `SHOWCASE` 里配置。
  - 这两个任务不能重新追踪，网页直达链接是 `#show=clip_C` 或 `#show=clip_D`。

**物体改名**：YOLOX 的类别名有时不准，可以在**第 2 步**的表格里点物体名称改名。第 3 步只显示名字，不能改，所有改名都在第 2 步完成。
- 操作：点名字就变成输入框，按 Enter 或点别处保存，按 Esc 取消；清空名字就恢复成 YOLOX 原来的类别。
- **只能用英文**：字母、数字、空格和 `. _ - ( ) ' & + /`。视频里的标签用 OpenCV 绘制，画不出中文。网页和后台都会检查，不符合的名字不保存。
- 名字按"物体"保存：一个物体合并后的所有编号（例如 #1 和并进来的 #6、#8）显示同一个名字，第 3 步的表格同步显示。
- 改名后，名字下方会小字注明 YOLOX 原来的类别。
- 名字保存在任务的 `job.json`（`labels` 字段），刷新页面后仍然有效。
- **重画视频**：改名后表格立刻更新，视频里的名字要点第 2 步的 *Redraw videos with new names* 才会更新。
  - 名字改了但还没重画时，按钮会高亮，旁边有红字提示。
  - 重画只做一件事：按已经保存的检测框和 mask 重画检测预览视频、追踪结果视频、并排对比视频，并重写 CSV 和 mask 压缩包。不重新检测，也不重跑 SAM 2，10 秒左右的片段约 10 秒完成。
  - 如果在追踪之前就改了名，追踪时会直接用新名字画视频，不用再点重画。
- 轨迹表 CSV 多了一列 `name`（显示的名字），`class` 列保留 YOLOX 原来的类别。
- Test results 页是只读的，不能改名。

## 流程
1. **选视频**：上传视频，或者选 `test_clips` 里的测试片段。最长 30 s，最长边缩到 1280。
2. **检测并关联成实例**（`prepare`）：
   - YOLOX-S 逐帧检测，置信度 0.25。
   - `link_tracks` 把检测框连成一条条轨迹：
     - 同类别的框之间用 IoU 贪心匹配，门槛 0.3。
     - 按上一段的速度预测物体位置，允许中间漏检最多 8 帧。
     - 置信度 ≥ 0.4 的框才能新开一条轨迹。
     - 保留长度 ≥ 5 帧、最高分 ≥ 0.5 的轨迹。
   - 同一类的多个物体（例如 3 把椅子）会**各自编号**。编辑器是按类别分组的，这一点是两者的区别。
   - 生成 `boxes.mp4`，只画检测框和编号。
3. **勾选实例**：可以按类别一键选或取消，一次最多 16 个（包括手动框选的物体）。
   - **手动框选**（`add_manual`）：YOLOX 只认识 COCO 的 80 类，扑克牌、纸袋这类物体不会出现在列表里。在第 2 步检测视频下方：
     1. 拖动滑块，选一帧物体清楚的画面；
     2. 在画面上拖一个框；
     3. 填写名字（只能用英文），点 *Add object*。
   - 手动加的物体会接着已有编号往下编号，默认勾选，列表里注明 "added by hand"，可以点 *remove* 删掉。
   - 追踪时，手动框选的那一帧就是提示帧，和检测到的实例一起交给 SAM 2。
   - 例子：clip_F01 里 K、Q 两张牌检测不到，手动框选后都追踪到了，分别是 151/151 帧和 150/151 帧。
4. **SAM 2 同时追踪**（`track`）：
   - 每个实例只在一帧上给一个框作为提示。这一帧由 `prompt_frame` 选出：置信度高、和同一帧里其他框重叠少。
   - 所有实例一起先向后、再向前传播。
   - 每帧存一张**标签图**：像素值 = 编号，0 = 背景。几个 mask 重叠的像素归 SAM 2 打分最高的那个，所以每个像素只属于一个物体。
   - 标签图再做 5×5 中值滤波，去掉碎点。
5. **合并重复编号**：满足下面任一条件，就当作同一个物体，保留编号小的：
   - 两个编号都出现的帧里，mask 的 IoU > 0.5；
   - 两者同一类，而且小的有 80% 以上落在大的里面（检测器只框到了物体的一部分）。

   常见的原因是物体出画后又回来、被手挡住，检测器给了它新编号，而 SAM 2 的记忆能认出是同一个物体。合并后的类别按检测帧数投票决定。
6. **输出**：
   - `tracked.mp4`：彩色 mask、轮廓和 "#编号 类别" 标签。
   - `compare.mp4`：原视频和追踪结果左右对比。
   - `tracks.csv`：每个物体每帧一行，字段为 frame、time_s、id、class、name、x、y、w、h、mask_area_px。
   - `label_masks.zip`：每帧一张标签图 PNG。
   - 网页上有每个物体的时间轴：粗条是 SAM 2 的 mask，细条是 YOLOX 的检测框；点击时间轴可以跳到对应时刻。

## 已知限制
- 只能识别 COCO 的 80 类，检测器不认识的物体（例如纸袋）这里不会出现。需要的话可以用编辑器的手动框选。
- SAM 2 的时间大致和"帧数 × 实例数"成正比，实例多时需要几分钟。
- 两个同类物体长时间完全重叠时，编号可能互换。合并规则偏保守，宁可留下两个编号，也不把不同物体合在一起。
